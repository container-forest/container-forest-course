# container-forest — навчальний проєкт

Матеріали навчального проєкту курсу ООП (2026–2027) команди ІПС-22: опис проєкту, облік елементів лабораторних робіт, ретроспективи бібліотек і правила роботи команди.

Сам проєкт розвивається в [container-forest/container-forest](https://github.com/container-forest/container-forest). Ці документи звідти винесено, щоб основний репозиторій був звичайним проєктом з відкритим кодом, а не здачею лаб. Історію комітів, що їх змінювали, збережено; номери PR у повідомленнях комітів ведуть в основний репозиторій.

## Перший семестр

Код, на який посилаються документи, — на тегу [`course/semester-1`](https://github.com/container-forest/container-forest/tree/course/semester-1) основного репозиторію.

| Документ | Що в ньому |
|---|---|
| [docs/project-overview.md](docs/project-overview.md) | Команда й ролі, мотивація, можливості за етапами, ООП-дизайн, аналіз аналогів, зв'язок із лабами |
| [docs/course-requirements.md](docs/course-requirements.md) | Вимоги курсу й рішення команди щодо зарахування |
| [CONTRIBUTIONS.md](CONTRIBUTIONS.md) | Облік елементів лаб 1–3 для кожного учасника |
| [docs/retro/](docs/retro/README.md) | Ретроспективи зовнішніх бібліотек (лаба 3) |
| [docs/ai-usage.md](docs/ai-usage.md) | Як команда використовувала генеративний ШІ |
| [docs/team-rules.md](docs/team-rules.md) | Правила роботи в команді |

## Наступні семестри

Облік і звіти пишемо тут, а не в основному репозиторії. Посилання на код — постійні (на тег або коміт основного репозиторію), щоб вони не ламалися з розвитком проєкту. Наприкінці семестру ставимо в основному репозиторії тег `course/semester-<N>`.
